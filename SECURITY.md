# Security Policy

## Supported Scope

This repository is a portfolio project and does not process live production data.
It is designed to demonstrate how executive briefing signals can be modeled,
scored, and translated into operational recommendations.

## Reporting

If you identify a security issue in this project, please do not open a public issue
with sensitive details. Instead, contact the repository owner through their public
site:

- [Kinetic Gain](https://kineticgain.com/)

## Safe Defaults

- No secrets are committed to the repository.
- Environment configuration is documented in `.env.example`.
- Sample data is synthetic.
- CI installs dependencies and runs tests on every push and pull request.
